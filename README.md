# Avito Moderator Desk

Система модерации объявлений. Модераторы могут просматривать, фильтровать и одобрять/отклонять объявления.

## Быстрый старт

```bash
# Frontend
cd frontend
npm install
npm run dev

# Backend (в другом терминале)
cd tech-int3-server
npm install
npm start
```

Откроется на http://localhost:5173

## Описание

Приложение позволяет модераторам:

- Просматривать список объявлений с пагинацией
- Фильтровать по статусу, категории, цене, поиску
- Сортировать по дате, цене, приоритету
- Одобрять объявления
- Отклонять с выбором причины
- Запрашивать доработку
- Просматривать статистику за день (4 метрики)

Три основные страницы:
- /list - Список объявлений с фильтрацией
- /item/:id - Деталь объявления с историей модерации
- /stats - Статистика модератора
